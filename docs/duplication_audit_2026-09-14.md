# Code duplication audit — 2026-09-14

Inventory of duplicated, near-duplicated, and unused code across `src/`, `tests/`,
`tools/`, `scripts/` and `CMakeLists.txt`. **No code was changed.** Every row is a
candidate for a later merge/delete decision; "Suggested action" is the auditor's
proposal, not a commitment. Fidelity rules in [project_goals.md](project_goals.md)
still apply: several rows are marked *keep* because the duplication is a
DOS-literal split that must not be folded.

## Method

| Pass | Tool | Scope |
|------|------|-------|
| Exact repeated line blocks | hash-based shingle detector (8+ significant lines, comments/braces stripped) | `src/`, `tests/`, `tools/` |
| Unreferenced global symbols | `nm` over every object of a fresh `-ffunction-sections` build (core + main + 66 test/tool targets), then grep for intra-file use | `src/` |
| Unused static functions / variables | `-Wall -Wextra` build log | `src/` — **zero hits**, the compiler already keeps statics clean |
| Static name collisions across files | regex over `static` definitions | `src/` |
| Unregistered / unincluded files | CMakeLists cross-check | `src/`, `tests/`, `tools/` |
| Semantic duplicates, stale variants, dead paths | nine read-only Opus agents, one per cluster, each verifying "unused" claims across `src/`, `tests/`, `tools/` | all |

Row IDs are `<cluster>-<n>`: **AE** ai_euro, **AC** ai_contact, **AK** ai core/diplo/king/goals/popup,
**GL** game_loop, **UN** units/combat, **CO** colony/turn, **SC** europe/reports/screens,
**IN** map/ui/assets/sound/save, **TT** tests/tools/scripts. Kind vocabulary:
semantic-dup, near-dup, wrapper, parallel-table, dead, stale-variant, copy-paste.

  No action beyond row 33/34.

  `ai_goals_clear_primary_slot` (only ai_goals.c:206), `ai_popup_chain_key` (only ai_popup.c:88),

  `ai_goals_filter_profession_by_distance_wealth` (only ai_goals.c:1361, 1397 + tests) → all `static`.
  `ai_king_crown_nation` must stay non-static: the inline `ai_king_crown_nation_col1` in ai_king.h calls it.
- **Status-string sniffing as control flow** (not duplication, but a repeated fragile pattern worth one
  decision): `ai_diplo_tag_from_status` (ai_diplo.c:1058-1069) picks a popup tag by `strstr`-ing English
  prose out of `ctx->status`, and ai_king.c:5458-5461 suppresses a notification the same way
  (`strstr(ctx->status, "refuse") || ... "raises taxes" || ... "Congress notes"`). Both break on any
  GAME.TXT/LABELS.TXT wording change. Suggest a small `ctx->status_kind` enum instead.
- Reachability caveat for rows 1-12: `ai_euro_use_full_dispatch` reads the environment on every call, so the
  fixture region is *live code from the compiler's point of view* — deleting it changes what
  `AI_EURO_EARLY_FIXTURE=1` does. docs/port_plan.md:608 documents that flag as a bisect aid, so the delete is
  a policy call, not a pure cleanup. If it is kept, rows 2-9 should at minimum be rewired to the ai_euro.c
  twins rather than left as divergent second implementations (row 2's copy is already behaviourally
  different: no map bounds check, no foundability fallback).
