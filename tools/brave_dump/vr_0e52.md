# `VR_0E52` — hang after loader returns (1816 thunk JMPF)

## Goal

Capture the **outer** far caller of `FUN_4d56_1816` once the overlay loader
has finished (clean stack), without poking EMS-mapped code.

## Failures

| Ver | Exit / symptom | Cause |
|-----|----------------|--------|
| v1 | freeze at boot | Hook `@0E52` broke `POP [397F]` |
| v2 | **19** | `evm0015` — near-JMP to cave `3B76` (Virtual Page) |
| v3 | **20** | `evm0020` — `ES:[ret]` peek = *Illegal alteration of EMS mapping state* |

## Result — `vr_0e52` (v4)

**Hang fired.** Live thunk `@0x22858` = `9A 52 0E 30 19 EB FE 18 81 CC`
(aliases `2042:2430` / `224A:03B0` / `1451:E340`).

| Item | Value |
|------|-------|
| Game | `DS:5394` nation=`3`, units=`46` (same mid-turn as `dump_1816`) |
| Saved CS:IP | `1451:0064` / `DS=ES=A000` / `SS:SP=237D:0448` — **IRQ/VGA**, not hang |
| Hang site | still `EB FE` on thunk JMPF |
| Outer (game stack) | **`1930:1554`** at `SS≈2385:E8C4` (under IRQ frame) |

IRQ frame on game stack (`2385:E8BE`): `IP/CS/flags` then **`1930:1554`**.
`1930:1554` is the overlay **Return Vector** (same forged ret as `dump_1816`
inside `FUN_4d56_1816`). No static `CALLF` to thunk phys `0x22850` in Memory.

**Conclusion:** After the loader returns, the far return waiting under the
JMPF is still the overlay Return Vector — not a year-loop / `130d` edge.
Thunk entry is overlay-dispatch; peels of `1554` remain the open XREF, not
another loader hang.
