# Return Vector / `1930:1554` — static map + forge hang

Goal: name who dispatches `FUN_4d56_1816` (Indian nation turn). Prior hangs
(`VR_1816`, `VR_1930`, `VR_0E52`) only showed body live via resident thunk and
far ret always **`1930:1554`**. This note maps that vector and peels the forge.

CS1930 file base in `COLONIZE/VICEROY.EXE`: **`0x13450`**.

## Chain (proven)

```
caller  →  overlay enter  →  1930:2A02 forges ret to 1554
        →  resident thunk 0x1C9A0  (CALLF loader → JMPF 1816)
        →  4d56:1816 body
        →  RETF → 1930:1554 → JMP 1446 → epilogue → real caller
```

## `1930:14F0`–`1600` (Return Vector window)

| Site | Stock / live | Role |
|------|----------------|------|
| `"Return Vector"` | `@15AF` | ASCII marker |
| `14FC` | hang miss (prior) | not the live ret edge |
| **`1554`** | `E9 EF FE` → **`JMP 1446`** | **Not a handler** — epilogue entry |
| `1446` | pop ES/DS/SI/DX/BX/AX; clear `[39E1]`; POPF; **RETF** | Overlay-manager epilogue |

| `15CF` | stock `9A 00 00 00 00` → live `CALLF CC81:1816` | **Dead linear path** (only mem hit for `CALLF *:1816`) |

No static `CALLF`/`JMPF` to `14FC` / `1554` / `15E0` in EXE or dumps.

## Forge — `1930:2A02` (file `0x15E52`)

Callers pass **`SI`** = ptr to far return on stack; **`BX`** = overlay handle
(`[3958]` path).

1. Head: compare `[SS:SI+2]` to loader seg, set flags, push regs…
2. `AND DX,3FFF` / `DEC DX` → overlay index
3. At **`2A4D`**: `MOV AX,1554` / `MOV DX,CS` then **`XCHG` onto `[SS:SI]` /
   `[SS:SI+2]`** — forge ret to Return Vector
4. Saves **real** caller IP/CS onto queue at far ptr **`[CS:3952]`** (10-byte
   entries); advances tip `+0xA`
5. Near `CALL 2A02` sites in CS1930 include `142C`, `1482`, `0495`, `069F`,
   `0FC5`, …

**Implication:** the `1930:1554` seen under `1816` is forged. True year-loop
caller is on the **queue** / still in `[SS:SI]` **before** the `2A4D` XCHG.

`[3952]` in `dump_1816` looked like wrong EMS bank — do not trust queue words
from that dump alone.

`CALLF 2042:0676` → mid-pass `1b3a` only — **no** direct `1816`.
