# Return Vector / `1930:1554` — static map + forge hang

Goal: name who dispatches `FUN_4d56_1816` (Indian nation turn). Prior hangs
(`VR_1816`, `VR_1930`, `VR_0E52`) only showed body live via resident thunk and
far ret always **`1930:1554`**. This note maps that vector and peels the forge.

CS1930 file base in `COLONIZE/VICEROY.EXE`: **`0x13450`**.

## Chain (proven)

```
caller  →  overlay enter  →  1930:2A02 forges ret to 1554
        →  resident thunk 0x1C9A0  (CALLF loader → JMPF 1816)
        →  4d56:1816 body
        →  RETF → 1930:1554 → JMP 1446 → epilogue → real caller
```

## `1930:14F0`–`1600` (Return Vector window)

| Site | Stock / live | Role |
|------|----------------|------|
| `"Return Vector"` | `@15AF` | ASCII marker |
| `14FC` | hang miss (prior) | not the live ret edge |
| **`1554`** | `E9 EF FE` → **`JMP 1446`** | **Not a handler** — epilogue entry |
| `1446` | pop ES/DS/SI/DX/BX/AX; clear `[39E1]`; POPF; **RETF** | Overlay-manager epilogue |
| `15CD` | `EB 3D` | Skips dead `15CF` |
| `15CF` | stock `9A 00 00 00 00` → live `CALLF CC81:1816` | **Dead linear path** (only mem hit for `CALLF *:1816`) |

No static `CALLF`/`JMPF` to `14FC` / `1554` / `15E0` in EXE or dumps.

## Forge — `1930:2A02` (file `0x15E52`)

Callers pass **`SI`** = ptr to far return on stack; **`BX`** = overlay handle
(`[3958]` path).

1. Head: compare `[SS:SI+2]` to loader seg, set flags, push regs…
2. `AND DX,3FFF` / `DEC DX` → overlay index
3. At **`2A4D`**: `MOV AX,1554` / `MOV DX,CS` then **`XCHG` onto `[SS:SI]` /
   `[SS:SI+2]`** — forge ret to Return Vector
4. Saves **real** caller IP/CS onto queue at far ptr **`[CS:3952]`** (10-byte
   entries); advances tip `+0xA`
5. Near `CALL 2A02` sites in CS1930 include `142C`, `1482`, `0495`, `069F`,
   `0FC5`, …

**Implication:** the `1930:1554` seen under `1816` is forged. True year-loop
caller is on the **queue** / still in `[SS:SI]` **before** the `2A4D` XCHG.

`[3952]` in `dump_1816` looked like wrong EMS bank — do not trust queue words
from that dump alone.

## Thunk bank (~file `0x1C9A0`)

12-byte records: `CALLF 110d:0DAB` + `JMPF target` + **2-byte overlay id**.

| Item | Value |
|------|-------|
| `1816` slot | `9A AB 0D 0D 11 EA 16 18 00 00 **0C 00**` |
| Overlay id | **`0x0C`** |
| Neighbors (same id) | `14fe`, `2154`, `2820`, `152e`, … |
| Reloc load seg | `1A1F:03B0` (aliases `2042:2430` / `224A:03B0`) |

No static `CALLF *:03B0` / `*:2430` in EXE or dumps. Year loop `@0xb751` does
`CALLF 2042:0676` → mid-pass `1b3a` only — **no** direct `1816`.

## Hang probe — `VR_2A02`

Phase 1 did not name a year-loop `FUN_*`. Probe the forge edge (EMS-safe):

```bash
# → COLONIZE/VR_2A02.EXE
```

| Item | Value |
|------|-------|
| Hook | `1930:2A4D` `MOV AX,1554` → `E9` to cave |
| Cave | `1930:294D` (`evm0022` string hole — **same page** as `2A02`) |

No distant cave, no reloc `EB FE`, no `ES:[ret]` EMS peek.

### Repro

Expect hang around **load / first overlay-0C use** (may black-screen before
mid-turn). Save as `dosbox-x-dumps/vr_2a02_v3`.

```bash
python3 tools/brave_dump/parse_2a02_dump.py dosbox-x-dumps/vr_2a02_v3
```

### Result — `vr_2a02` (v1, false positive)

Black screen right after load. Hang fired on **overlay `0x0B`**, not `0x0C`.

| Item | Value |
|------|-------|
| Remark | `after loading` |
| CPU | `BX=800B` (`&3FFF → 0x0B`), `AX=000B`; `CS:IP` dump often IRQ/`28f7` |
| Hang site | cave `EB FE` @ `1930:2977` |
| Game | `nation@5394=0`, `units@539c=46` (loaded, not mid-AI) |
| Cause | v1 filter included `0x0B`/`0x0D`; many thunks use those ids |

### Result — v2 (no hang)

`(BX&3FFF)==0x0C && nation==3` never fired through mid-turn. Likely: first
`0x0C` forge is while `nation≠3` (load), and later forges may use **`BX==0`**
(still hits `2A4D`) so the id filter misses the mid-turn path.

### Result — v3 (`dosbox-x-dumps/vr_2a02_v3`)

Hang during **AI turn** (not at load). Overlay id correct; caller is
**manager-internal**, not year-loop.

| Item | Value |
|------|-------|
| Game | `nation@5394=3`, `units@539c=46` (same window as `dump_1816`) |
| CPU | `BX=800C`, `AX=000C`; `SS:SI` on manager stack `237d` |
| `[SS:SI]` before forge | **`1930:238b`** — mid overlay-manager resume (after `237c` load path) |
| Under SI | also `1930:1626` (queue unwind) |
| `2385:7000` log | zeros (EMS / wrong DS) — ignore |
| Thunk | live `1816` still `@0x22858`; no static `CALLF` to it |

So first mid-turn `0x0C` forge is the overlay manager fixing its own resume
(`238b`), not a `130d`/`281f` edge. Year-loop `FUN_*` still open.

### Result — v4

Filter: `(BX&3FFF)==0x0C` **and** `[SS:SI+2] != 0x1930` (external far ret).
Log at **`CS:29C0`**. Rebuild: `patch_2a02_hang.py` → save `vr_2a02_v4`.
